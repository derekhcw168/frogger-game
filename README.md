# 🐸 青蛙過街 2：3D 跨越冒險 (Frogger 3D Odyssey)

本專案參考著名 3D 動作大作**《青蛙過街2》(Frogger 2: Swampy's Revenge)** 的等級、風格與視覺效果，使用 **Three.js (WebGL)** 現代 3D 引擎全新打造！具備 3D 體素立體風格、流暢的拋物線彈跳物理、5 隻走失小萌蛙救援任務、青蛙專屬技能系統（超級跳、伸長舌、超能蛙鳴）、5 大特色主題世界，以及現代立體音效。

---

## 🌟 現代 3D 遊戲特色

### 1. 拯救 5 隻迷失小萌蛙 (Rescue 5 Baby Frogs)
- 每一關的目的不僅僅是穿越地形，更要在 3D 世界中探險，找出並拯救走失的 5 隻彩色小青蛙（紅、藍、黃、紫、粉）！
- 救起的小青蛙會縮小並歡樂地爬上主角背後排隊（Stacking Backpack），滿 5 隻抵達終點傳送荷花陣即可進入下一世界！

### 2. 青蛙超能力專屬技能 (Frog Abilities)
- 🚀 **超級大跳 (Super Hop)**：按 `空白鍵` 或 `J` 鍵（或點擊技能鍵），蓄力大躍進 2 格距離，越過深溝、巨石或高牆障礙！
- 👅 **長舌抓捕 (Tongue Grab)**：按 `E` 鍵 或 `K` 鍵，瞬間吐出粉紅長舌，抓取前方的金幣、飛蟲與螢火蟲（補血得分）！
- 📢 **超能蛙鳴 (Power Croak)**：按 `Q` 鍵 或 `L` 鍵，釋放 3D 聲波光環，指引附近隱藏小青蛙的具體方位！

### 3. 5 大特色 3D 冒險世界 (Themed Worlds)
1. **世界 1：花園小溪 (Suburban Garden & Brook)**：割草車、玩具賽車、小溪流、漂浮木條、荷葉蓮花。
2. **世界 2：古代神廟 (Ancient Temple & Ruins)**：古代石柱、滾動巨石陷阱、急流瀑布、大嘴食人花。
3. **世界 3：幽靈古堡 (Haunted Manor)**：陰森古堡、遊蕩幽靈、深紫毒液河。
4. **世界 4：熔岩地穴 (Volcano Lava Caverns)**：翻滾赤紅熔岩、下沉玄武岩石板、熔岩火車。
5. **世界 5：賽博科技塔 (Cyberpunk Neon Tower)**：發光霓虹地磚、懸浮飛車、電子數據脈衝光河。

### 4. 現代 3D 視覺與光影
- **立體等軸斜俯視相機**：第三人稱平滑跟隨（Camera Lerp），兼顧開闊視野與強烈 3D 空間感。
- **純程序化 3D 體素幾何體**：零外部模型載入延遲，電腦或手機皆可極速秒開！
- **即時軟陰影與動態光效**。

### 5. 跨平台操作支援
- **電腦端**：
  - `↑ ↓ ← →` 或 `W A S D`：3D 網格跳躍移動
  - `空白鍵 (Space)` 或 `J` 鍵：超級大跳
  - `E` 鍵 或 `K` 鍵：長舌抓捕
  - `Q` 鍵 或 `L` 鍵：超能蛙鳴
- **手機 / 平板**：
  - 螢幕手勢滑動（上下左右滑動跳躍）
  - 畫面下方現代技能大按鈕
