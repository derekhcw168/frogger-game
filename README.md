# 🐸 青蛙過街 2：3D 跨越冒險 DX (Frogger 3D Odyssey DX)

全新升級 **Toy Diorama 微縮模型風 × UnrealBloom 霓虹輝光版**！使用 **Three.js (WebGL)** 與 **Web Audio 程序化多聲部合成器** 打造，零外部模型與音檔依賴，雙擊 `index.html` 或透過 GitHub Pages 皆可極速秒開！

---

## ✨ 全新 DX 旗艦升級亮點

### 1. 五大特色生態世界 × 專屬 3D 機關與微縮造景
1. **🌸 世界 1：花園小溪 (Suburban Garden & Brook)**
   - 旋轉刀盤割草車、流線跑車、鄉村木欄皮卡、預警下潛烏龜群、櫻花花瓣微風粒子。
2. **🏛️ 世界 2：古代神廟 (Ancient Temple & Ruins)**
   - 符文翻滾巨石、黃金衝車、張嘴巨鱷浮台、安全島大嘴食人花、可觸發時空緩速的水晶機關。
3. **👻 世界 3：幽靈古堡 (Haunted Manor & Graveyard)**
   - 暗夜紫霧籠罩、幽冥靈車與飄忽遊蕩幽靈（可用「超能蛙鳴」直接震散得分並驅散濃霧！）。
4. **🌋 世界 4：熔岩地穴 (Volcano Lava Caverns)**
   - 熔岩重裝火車、踩踏後裂紋發亮並倒數下沉的玄武岩石板、定時冒泡噴發的熔岩間歇噴泉。
5. **🌃 世界 5：賽博科技塔 ＋ 終極 Boss 決戰 (Cyberpunk Neon Tower & Final Boss)**
   - 懸浮飛車、攔截無人機、霓虹橫向加速傳送帶；救齊 5 隻小萌蛙推進至塔頂競技場後，迎戰三階段終極頭目 **「🐲 機械巨鱷皇 Mecha-Swampy Rex」**！

### 2. 戰術級三大青蛙超能力（支援關卡機關與 Boss 戰互動）
- 🚀 **超級大跳 (Super Hop)**（`空白鍵` / `J`）：向前跨越 2 格飛越矮車、滾石與橫掃雷射，落地釋放黃金震波重創頭目裝甲！
- 👅 **彈力長舌神技 (Tongue Grab)**（`E` / `K`）：自動扇形鎖定面朝方向，可吸收金幣與補血螢火蟲、**隔空救援遠處小萌蛙**、啟動水晶緩速機關，更能在頭目張嘴過熱時**扯出超載能量核心**造成暴擊！
- 📢 **超能蛙鳴 (Power Croak)**（`Q` / `L`）：釋放雙層聲波光環與 **3D 方位指南光箭**，可震散古堡幽靈、驅散迷霧、短暫緩速周圍車流，並能將頭目發射的電漿球**完美彈反轟回 Boss**！

### 3. 3D 萌蛙造型工坊、永久天賦升級、三星評級與成就圖鑑
- **👕 6 款精緻 3D 造型與專屬拖尾**：經典翠綠蛙、暗影忍者蛙（紅頭巾＋背負小太刀）、霓虹機甲蛙（全息護目鏡＋雙肩噴射器）、皇家黃金蛙（24K 純金＋紅寶石皇冠）、幻影幽靈蛙、赤焰熔岩蛙。
- **⚡ 3 大永久天賦強化**：靈巧氣囊（縮短技能冷卻）、彈力神舌（提升長舌距離）、生命護符（提升生命上限至 6 顆心）。
- **⭐ 關卡三星挑戰與 8 大成就徽章**：附帶中途蓮花存檔點、預輸入緩衝（Input Buffering）絲滑連跳手感與連擊倍率加成！

### 4. 五界程序化立體聲配樂與雙視角智慧運鏡
- **6 首程序化多聲部配樂**：每個世界與 Boss 戰皆擁有獨立編曲的即時合成背景音樂與 3D 左右聲道定位音效。
- **雙視角與畫質切換**：支援 `C` 鍵一鍵切換「🎥 經典斜俯視微縮視角」與「🎬 追尾越肩動作視角」，並可隨時切換「✨ 極致輝光 / ⚡ 省電高幀率」模式。

## 🎮 操作指南

- **移動跳躍**：`W A S D` 或 `↑ ↓ ← →`（手機支援全螢幕滑動手勢與左下角虛擬十字鍵）
- **超級大跳**：`空白鍵 (Space)` 或 `J`
- **長舌神技**：`E` 或 `K`
- **超能蛙鳴**：`Q` 或 `L`
- **切換視角**：`C` 鍵 或 右下角 `🎥` 按鈕
